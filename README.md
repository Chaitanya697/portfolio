# The Chaitanya Chronicles: Portfolio of Chaitanya P Desai

**Live:** https://chaitanya697.github.io/portfolio/

My portfolio, told as a comic book: a cover, a 30-second recap, then chapters for experience, projects, research, current work, education, leadership, skills and contact.

## Features

- **Comic-book design system:** inked panels, captions, sound effects and halftone textures, kept clean and professional.
- **A caped sidekick** runs along the bottom of the page. He follows your mouse, his eyes track the cursor, he wiggles when you move over him and does a flip with a fun fact when you click him. He changes outfit for each chapter.
- **Quick jump:** press `/` to jump to any chapter, project, résumé or action.
- **Responsive:** the panels stack on phones, and the page respects reduced-motion settings.
- **Lightweight:** hand-written HTML, CSS and JavaScript with no frameworks or build step.
- A few hidden extras.

## Structure

```
index.html          page shell and cover
assets/style.css    design system
assets/app.js       content, panels, mascot, quick jump
assets/resume/      résumé PDFs
```

To edit content, change the data arrays at the top of `assets/app.js`.
